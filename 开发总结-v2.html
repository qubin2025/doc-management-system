五、开发经验教训

5.1 技术选型

决策结果教训
Draw2D 集成失败第三方Canvas库与React兼容性差，运行时错误无法修复
自定义 SVG 路由部分成功基础路由可用，但箭头/锚点/编辑交互投入产出比低
draw.io 嵌入成功成熟方案，Vite代理解决网络问题，postMessage传递数据
本地化部署失败23MB静态文件下载成功但JS动态加载机制无法工作
多模型AI路由成功DeepSeek+GLM-4V+Qwen-VL自动切换，视觉模型需base64传图

5.2 开发规则

  1. 新模块模板：参照 GuideChapter.tsx 结构
  2. Modal 规范：fixed overlay + 白卡片 + 头/体/底三区
  3. 图标统一：只使用 lucide-react
  4. 数据持久化：localStorage + API 双写
  5. 禁止：React Router、Redux、CSS Modules、非MIT库、Class组件
  6. 文件编辑后先编译验证：避免遗留语法错误
  7. 大文件用 sed/awk 批量处理：行号变更后需重新确认
