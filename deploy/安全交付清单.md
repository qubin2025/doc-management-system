# 部署安全交付清单

> 交付前逐项确认

## 一、代码安全验证

- [x] 前端 `.env` 中无 API Key（已移除，仅保留 VITE_API_URL）
- [x] 后端 `backend/.env` 已加入 `.gitignore`，不会提交到版本库
- [x] `backend/.env.example` 仅含占位符，无真实密钥
- [x] `node_modules/` 已加入 `.gitignore`
- [x] 数据库文件 `backend/data/*.db` 已加入 `.gitignore`
- [x] 上传文件目录 `backend/files/` 已加入 `.gitignore`
- [x] 备份目录 `backend/backups/` 已加入 `.gitignore`

## 二、部署前操作（目标电脑上执行）

### 必须操作

1. **创建 backend/.env** — 填入真实 API Keys
   ```bash
   cp backend/.env.example backend/.env
   # 编辑填入：
   #   DEEPSEEK_API_KEY=sk-xxx
   #   ZHIPU_API_KEY=xxx
   #   QWEN_API_KEY=sk-xxx
   #   JWT_SECRET=生成64位随机字符串
   ```

2. **生成唯一 JWT_SECRET**
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
   将输出替换 `backend/.env` 中的 `JWT_SECRET`

3. **修改默认管理员密码**
   ```bash
   cd backend && node -e "
   const bcrypt = require('bcrypt');
   const { getDb } = require('./db.js');
   getDb().prepare('UPDATE users SET password_hash=? WHERE username=?')
     .run(bcrypt.hashSync('你的强密码', 10), 'admin');
   "
   ```

### 建议操作

4. 删除或禁用 user1~user8 测试账号
5. 生产环境设置 `NODE_ENV=production`
6. 确认 `CORS_ORIGIN` 限制为实际域名（非 `*`）
7. 配置防火墙：仅开放 80/443（Nginx），3000 仅本机访问

## 三、不应包含在交付包中的文件

| 文件 | 原因 | 处理 |
|---|---|---|
| `backend/.env` | 含真实 API Key | ❌ 不要复制，用 .env.example 代替 |
| `backend/data/` | 含数据库+用户数据 | ❌ 不要复制，新部署会自动创建 |
| `backend/files/` | 含上传的文件 | ❌ 不要复制 |
| `node_modules/` | 可在目标电脑安装 | ❌ 不要复制 |
| `dist/` | 可在目标电脑构建 | ❌ 不要复制（或复制但需验证） |
| `src/components/*.bak` | 开发备份文件 | ❌ 不要复制 |
