## 三、测试版本包含的核心功能

1. **项目管理**：项目台账、项目详情、WBS 目标分解、甘特图、成本/资源/风险/供应商/干系人管理
2. **工程资料管理**：文档上传（multipart 流式，单文件上限 200MB，ZIP 解压解析 50 个文件）、资料归集、向量化知识库、AI 索引
3. **知识图谱**：Neo4j 实体关系图谱、GraphRAG 语义检索、法规条款图谱
4. **AI 能力**：DeepSeek 聊天/审查/方案生成、通义 Embedding 语义搜索、GLM-4V/千问视觉识别
5. **全过程咨询指南**：指南模块 5 大章节、时序逻辑图（draw.io 嵌入，支持保存/导出 PNG/SVG/重置连线）、表格模板
6. **日报与移动端**：手机日报上传（含水印照片）、PWA 离线支持、移动端知识浏览
7. **系统功能**：多用户 RBAC 权限、审计日志（886 条）、全局搜索（Ctrl+K）、StateView 状态管理、虚拟列表、主题配色（暖色/冷色/暗色三套，文字下拉选择）、面包屑导航
8. **部署运维**：Docker Compose 一键部署、PM2 配置、Nginx 反代、备份/恢复接口

## 六、重要声明与风险提示

1. **本版本为测试版**，用于试运行与功能验证，不建议直接承载正式业务数据。
2. **管理员账号密码为弱密码**（admin123），上线前必须修改（见待完善清单 P0-1）。
3. **前端 .env 含真实 API Key**，仅限本机，严禁将 `.env` 文件随交付包分发（见待完善清单 P0-2）。
4. LightRAG/PaddleOCR 为裸进程运行，机器重启后需手动拉起（见运维手册）。
5. 后端启动日志中服务探针可能显示 OFFLINE 误报（Node fetch 走系统代理导致），以 `/api/health` 与 `/api/stats` 实时检查为准。
