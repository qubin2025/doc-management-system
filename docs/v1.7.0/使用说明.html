1. 系统概述

全过程工程咨询管理服务平台是一套面向建设工程领域的工程资料管理、全过程咨询指南执行跟踪、AI智能辅助分析的综合管理系统。系统覆盖项目从前期立项到竣工验收的全生命周期，提供资料归档、工作指南、进度管理、AI分析等核心能力。

项目说明
系统名称全过程工程咨询管理服务平台
版本号v1.7.0
支持规程DB11/T695-2025（建筑）、DB11/T808-2020（市政）
访问方式浏览器访问（Chrome / Edge / Firefox 推荐）
部署模式Docker 一键部署 / Node.js 手动部署 / Nginx 反向代理
数据存储SQLite 数据库 + localStorage 离线双模式

2. 快速入门

第1步：启动系统
双击 deploy/start.bat（Windows）或运行 bash deploy/deploy.sh（Linux），系统自动启动前端（5173端口）和后端（3000端口）。
第2步：登录
浏览器打开 http://localhost:5173，输入管理员账号登录。首次部署密码请在部署说明中查看。
第3步：创建项目
在项目入口页点击「创建项目」，输入项目名称即可开始使用。
第4步：选择规程
进入项目后选择建筑或市政规程，系统自动加载对应的资料分类表。
第5步：开始工作
上传工程资料、跟踪指南进度、查看仪表盘、使用AI助手。
系统支持离线模式：后端不可用时，数据自动存储到浏览器本地，后端恢复后自动同步。

3. 登录与账号管理

3.1 登录

输入用户名和密码即可登录。系统支持以下角色：

角色权限说明
admin系统管理员：用户管理、全量备份、所有项目访问
project_manager项目经理：创建项目、上传下载文档、使用AI
construction_unit建设单位：上传下载文档
viewer查看者：仅下载查看

3.2 注册新用户

登录页点击「注册」按钮，填写信息后提交。默认注册用户为待审批状态，需管理员在管理后台启用。

安全提示：登录接口设置了防暴力破解限流（15分钟内最多10次），连续失败将被临时锁定。

3.3 管理后台

管理员可进入管理后台进行：用户创建/编辑/删除、权限分配、账号启用/禁用等操作。

4. 项目管理

4.1 项目列表

登录后进入项目入口页，展示所有已创建项目的卡片列表。每个卡片显示：项目名称、创建时间、指南进度条、项目健康度指标。

4.2 创建项目

点击「创建项目」按钮，输入项目名称即可。可双击项目名称进行重命名。

4.3 编辑项目信息

悬停项目卡片，右下角出现「编辑」按钮。点击进入编辑对话框：

  • 基本信息：项目概况、建筑面积、建设规模、投资额、市政管线
  • 项目概况文件上传：上传项目相关的 PDF/Word/Excel 等文档
  • AI 自动填写：根据项目名称或上传的文档内容，AI 自动填充各字段
  • AI 分析报告：生成项目风险分析、进度评估、成本优化等专业报告
  • 自定义字段：可添加任意自定义键值对

5. 工程资料管理

5.1 资料列表

进入项目后，左侧为资料分类目录（A类/B类/C类/D类），右侧为对应分类下资料表格。支持按类别筛选、关键词搜索。

5.2 上传资料

上传步骤：
1. 点击资料行右侧的「上传」按钮
2. 选择文件（支持 PDF/Word/Excel/图片/CAD/ZIP/TXT/CSV，单文件≤50MB）
3. 系统自动记录版本号（V1.0起）、上传人、上传时间

5.3 文件安全

系统对上传文件进行多项安全检查：文件类型白名单验证、文件名路径穿越防护、路径包含验证。不含法文件类型将被拒绝。

5.4 下载与导出

支持单文件下载、批量 CSV 导出、ZIP 打包下载。导出功能在工具栏可找到。

6. 指南工作模块

按照《全过程项目管理工作指南（二次修订版）》设计的4大章节工作流：

章节内容子模块数
第1章 前期工作项目立项、可行性研究、用地规划许可、建设许可、施工许可10+
第2章 招标采购招标方案编制、资格预审、招标文件、评标定标、合同签订8+
第3章 工程施工开工准备、质量控制、进度管理、安全生产、变更签证12+
第4章 竣工验收及移交竣工预验收、专项验收、资料归档、工程移交、竣工结算10+

6.1 工作项勾选

每个子模块下有具体工作项，可逐个勾选纳入计划（蓝色）或标记完成（绿色）。支持一键全选/取消。

6.2 自定义工作项

点击子模块旁的「+」按钮添加自定义工作项，可设置：名称、时长、前置/后置子模块关联。自定义项可编辑和删除。

6.3 附件上传与版本管理

上传附件：
1. 点击工作项旁的「修改」按钮
2. 在对话框中选择文件上传
3. 系统自动编号版本（V1, V2, V3...）
4. 勾选工作项后，右侧显示附件数量 📎N
5. 点击附件数展开详情，可查看文件名、版本号，悬停显示删除按钮

6.4 进度跟踪

头部显示实时进度条（已选/总量），支持撤销操作（最近5步）。子模块可保存为模板，供其他章节复用。

7. 时序逻辑图

切换到「时序逻辑图」标签页，系统自动将已勾选的工作项生成时序逻辑关系图。基于 draw.io 嵌入式编辑器：

  • 自动布局：按子模块分列，工作项以卡片显示
  • 连线管理：蓝色虚线=计划中，绿色实线=已完成
  • 编辑器：支持拖拽节点、创建连线、同步连线到工作模块
  • 缩放：25%-200% 自由缩放，支持适应页面
  • 重置：一键恢复默认布局

8. 附表清单

各章节包含对应附表清单，与《全过程项目管理工作指南》附表格式一致：

  • 样本预览：点击「样本」查看附表模板格式
  • 文件上传：上传实际填写的表单文件
  • AI 自动填写：点击「AI 自动填写」智能填充表单内容
  • 编辑：在线编辑表单文本，支持导出

9. 项目仪表盘

进入项目后点击「仪表盘」入口，展示项目关键指标：

  • CPI（成本绩效指数）：已签合同/概算金额比
  • SPI（进度绩效指数）：实际进度/计划进度比
  • 完整度评分：已上传资料/应有资料比
  • 质量评分：综合评估质量等级
  • 告警列表：超期/异常指标自动告警
  • 多项目对比：切换不同项目查看指标变化

10. 计划管理

10.1 甘特图

在「计划管理」中查看项目计划的甘特图视图，支持任务时间线可视化。

10.2 网络图（CPM）

基于关键路径法（CPM）的项目网络图，支持：ES/EF/LS/LF 计算、关键路径识别、浮时分析、Excel计划数据导入。

11. 供应商库与造价管理

11.1 供应商库

维护合作供应商信息，包括：企业名称、资质等级、联系人、合作项目记录等。

11.2 造价数据

管理项目造价相关数据，支持指标计算与对比分析。

12. AI 智能助手

系统集成 DeepSeek 大语言模型，提供以下 AI 能力：

功能说明
AI 对话底部 AI 输入框 / 全页 AI 聊天界面，支持项目上下文感知
AI 表单填写根据表单类型和项目信息，自动生成填写内容
AI 项目分析基于项目数据生成风险分析、进度评估、成本优化建议
AI 文档感知上传项目文档后，AI 可读取文档内容智能提取关键字段
视觉模型支持 GLM-4V / Qwen-VL 多模态图像识别
语义搜索基于向量化的知识库语义检索
AI 功能需要配置 API Key（DeepSeek / 智谱 / 千问）。后端优先代理请求，前端作为 fallback。

13. 智能分析中心

「智能分析」入口提供：

  • 周期性扫描：自动检查工作项完成情况、表单缺失、指标异常
  • 异常检测：识别进度滞后、成本超支等风险
  • AI 建议：基于检测结果生成针对性改进建议

14. 知识库体系

14.1 知识库

工程管理相关知识文档的存储与全文检索，支持语义搜索。

14.2 知识图谱

工程管理领域知识的关系网络可视化展示。

14.3 政策库 & 制度规范库

政策法规与制度规范的分类浏览、全文搜索、附件管理。

15. 土储中心归档

提供土地储备中心归档移交资料的管理，包含86项标准归档资料清单。支持按项目对照填写，附带小红门再生水调水干线项目示例数据。

16. 数据备份与恢复

16.1 备份

首页工具栏中「备份」按钮：

  • 全部项目备份：数据库 + 所有上传文件打包 ZIP（需管理员权限）
  • 指定项目备份：单个项目的文档记录和文件 ZIP
备份通过安全加密的 Authorization Header 传输认证信息，不会在 URL 中暴露 token。

16.2 数据恢复

通过「导入」功能从 JSON 格式数据批量恢复文档记录。backup ZIP 解压后包含完整数据库文件和文件目录。

17. 常见问题

Q: 忘记管理员密码怎么办？

进入 backend 目录，运行：node -e "const bcrypt=require('bcrypt');const{getDb}=require('./db.js');getDb().prepare('UPDATE users SET password_hash=? WHERE username=?').run(bcrypt.hashSync('新密码',10),'admin')"

Q: 上传文件失败？

检查：1) 文件类型是否在支持列表中 2) 文件大小是否超过50MB 3) 文件路径是否有特殊字符 4) 后端 files 目录是否有写入权限

Q: AI功能提示"Key未配置"？

编辑 backend/.env 文件，填入 DEEPSEEK_API_KEY 等 AI Key 后重启后端服务。

Q: 数据是否会丢失？

系统采用双重存储策略：数据同时保存在后端 SQLite 数据库和浏览器 localStorage 中。建议定期使用备份功能导出 ZIP。

Q: 支持多少用户同时使用？

SQLite单机模式下建议10人以内。如需更大并发，可考虑迁移至 PostgreSQL。
