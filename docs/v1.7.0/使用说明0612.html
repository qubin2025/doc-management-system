一、系统概述与快速启动

🏗 双规程
建筑 DB11/T695-2025 + 市政 DB11/T808-2020，附录A数据已预置
🤖 AI驱动
DeepSeek聊天 + 通义Embedding + GLM-4V视觉，智能填写/分析/搜索
📋 指南数字化
4章40+子模块500+工作项，数字化跟踪全过程咨询指南
🔒 企业级安全
15项安全加固：路径防护/限流/加密/白名单/参数化查询
🐳 一键部署
Docker Compose / PM2+Nginx / Windows脚本 三方案
📡 离线双模式
localStorage+SQLite双重存储，断网自动降级
第1步：启动系统
Windows：双击 deploy\start.bat（自动安装依赖+启动前后端）
Linux：bash deploy/deploy.sh ｜ Docker：docker-compose up -d
第2步：打开浏览器
访问 http://localhost:5173（开发）或 http://localhost（Docker）
第3步：登录
使用管理员账号登录。首次部署密码见部署说明。
系统首次启动自动创建SQLite数据库和默认用户。AI功能需配置API Key。

六、时序逻辑图

图5：时序逻辑图 — draw.io嵌入式编辑器，泳道图展示工作项间时序关系

draw.io编辑器首次加载需联网，后续支持离线使用。连线修改通过「同步连线」按钮回写到工作模块。
