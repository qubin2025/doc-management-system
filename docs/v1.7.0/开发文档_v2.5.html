六、安全设计(15项)

措施实现
SQL注入防护全部better-sqlite3参数化(?)查询
路径遍历防护isPathSafe + path.basename + 白名单验证
文件类型白名单13种允许，拒绝.exe/.sh等
暴力破解防护登录15分/10次，注册1小时/5次
账号枚举防护禁用与密码错误统一返回401
密码安全bcrypt 10轮salt哈希
Token安全UUID Session+24h过期+数据库验证
CORS生产环境白名单控制
安全头X-Content-Type-Options/X-Frame-Options/X-XSS-Protection
