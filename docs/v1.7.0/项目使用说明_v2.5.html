一、快速启动

方式一：Docker 一键部署
docker-compose up -d — 自动启动前端(80)+后端(3000)+Neo4j(7687)+LightRAG(8000)
方式二：手动启动
Windows: 双击 deploy\start.bat
Linux: bash deploy/deploy.sh
方式三：开发模式
cd backend && node server.js（后端）
npm run dev（前端）
首次部署需配置 backend/.env 中的 DEEPSEEK_API_KEY 以启用AI功能。Neo4j和LightRAG为可选服务。

二、登录与账号管理

默认账号: admin / 首次部署密码见部署说明

角色权限
admin系统管理员：用户管理、全量备份、所有功能
project_manager项目经理：创建项目、上传下载、使用AI
construction_unit建设单位：上传下载文档
viewer查看者：仅下载查看
安全保护：登录限流15分/10次、bcrypt密码加密、Session24h过期、账号枚举防护

三、项目入口

登录后进入项目列表页。支持：创建项目、搜索筛选、双击重命名、查看指南进度、编辑项目详情。

项目详情支持AI自动填写（根据项目名称或上传文档智能提取建设规模/投资额等信息）。

底部AI输入框可发送工程咨询问题，DeepSeek上下文感知回答。

四、工程资料管理

支持 DB11/T695-2025（建筑）和 DB11/T808-2020（市政）双规程。

  • 资料分类：A类(决策立项)、B类(招标采购)、C类(工程施工)、D类(竣工验收)
  • 上传：PDF/Word/Excel/图片/CAD/ZIP/TXT/CSV，≤50MB，自动版本管理
  • 下载/导出：单文件下载、CSV导出、ZIP打包
  • 安全：文件类型白名单13种、路径穿越防护、参数化SQL

五、指南工作模块

按《全过程项目管理工作指南》设计4章工作流：前期工作→招标采购→工程施工→竣工验收。

  • 工作项勾选：蓝色=计划中，绿色=已完成，两步确认
  • 自定义工作项：添加/编辑/删除，设置时长、前后置依赖
  • 附件上传：自动版本编号V1/V2/V3…，上传人/日期自动记录
  • 时序逻辑图：draw.io嵌入式编辑器，泳道图可视化
  • 附表清单：样本预览、上传、AI自动填写、导出

七、施工组织设计审查（含专项方案）

操作流程：
1. 上传施工方案（支持PDF/Word/Excel/TXT，可批量多文件）
2. 自动解析文档内容（PDF前100页/40000字）
3. RAG检索匹配DB11/T695相关标准条款
4. AI逐章审查：合规/注意/不合格三级标记
5. 同步审查结果到知识图谱
6. 导出Word/TXT审查报告
离线模式：AI不可用时自动切换为关键词匹配分析（6项检查：编制依据/工程概况/施工部署/进度/质量/安全）

八、合同审查

上传合同文件 → AI逐条审查。检查8类风险条款：违约责任/工期延误/付款条件/争议解决/不可抗力/索赔/变更/解除合同。

风险等级：低🟢/中🟡/高🔴，每条列出问题和修改建议。

审查结果可同步知识图谱（合同节点→项目），导出Word报告。

九、招投标文件审查

上传招投标文件 → AI逐项检查7要素：投标人资格/评标办法/合同条款/技术规范/工程量清单/投标保证金/履约担保。

标记合规/注意/不合格项，注明法规依据，识别排他性条款。

十、AI方案生成

操作流程：
1. 选择方案类型（7种：施工组织设计/深基坑/塔吊安拆/模板支架/脚手架/临时用电/消防）
2. 填写项目参数（规模/地点/投资/类型/深度等）
3. AI逐章生成10个章节（编制依据/安全措施等4章100%自动注入标准条款）
4. 在线编辑各章内容
5. 完整性校验（关键词+字数+章节缺失检测）
6. 导出PDF/Word/TXT
支持保存模板类型、自动分块索引（段落级+重叠窗口）

十一、知识库

  • 全文搜索：Lunr.js 浏览器端倒排索引
  • 语义搜索：通义Embedding 768维向量 + 余弦相似度
  • 知识图谱：vis-network 2D + ForceGraph3D 3D双视图
  • LightRAG：Python微服务，文档自动实体抽取+混合检索
  • 政策库/制度规范库：分类浏览、全文搜索、附件管理
  • 土储中心归档：86项标准清单，示例数据

十二、管理后台

管理员入口：首页右上角齿轮图标。

  • 用户CRUD + 角色权限分配
  • 实时系统统计：项目数/文档数/用户数/运行时间
  • 系统健康状态：Neo4j连接/AI引擎/内存使用
  • 数据备份：单项目/全量ZIP打包
