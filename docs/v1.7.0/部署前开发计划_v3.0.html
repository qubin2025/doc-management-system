四、技术建议

图片识别终极方案

聊天中图片识别 7 次尝试均因浏览器端问题失败。推荐方案：

  1. 方案A（推荐）： 将安全巡检独立页面模式扩展到AI聊天 — 聊天中上传图片时，自动跳转到安全巡检页面，分析完成后将结果回填到聊天记录
  2. 方案B： 使用FormData Upload + 独立分析管道（当前安全巡检模式已证明可行），聊天中只显示分析结果引用
  3. 方案C： 部署到云服务器后，使用绝对公网URL，绕过Vite代理所有问题

部署架构

内网部署：Node后端 + Vite构建产物 → Nginx反向代理 → 无需SSL

外网部署：Nginx + Let's Encrypt + Cloudflare CDN → HTTPS → 公网访问

多租户方案

当前：SQLite单机 → 内网10-50用户够用

未来：PostgreSQL Schema隔离 → 支持500+企业客户
