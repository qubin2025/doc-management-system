三、RAG检索增强生成策略

3.1 本系统RAG架构

六层架构：文档解析 → 智能分块 → 向量化(DashScope 768维) → 向量存储(localStorage→IndexedDB) → 语义检索(余弦相似度Top-3) → 增强生成(上下文拼接)

3.2 三级降级链

RAGFlow(:9380 Docker企业级) → LightRAG(:8000 Python混合检索) → 本地向量库(localStorage/IndexedDB始终可用)

3.3 与云端RAG的安全对比

维度云端RAG（OpenAI Assistants）本系统RAG
文档存储位置AI厂商云端服务器浏览器 local/IndexedDB
检索索引厂商管理，不可控本地管理，完全可控
离线可用❌ 依赖网络✅ 本地向量库离线可检索
