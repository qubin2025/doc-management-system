## 一、主题系统架构

### 三层模型

```
themeEngine.ts (状态管理)
    ↓ setTheme() → applyTheme()
index.css (CSS 变量 + .dark 全局覆盖)
    ↓ data-theme="dark" + .dark class
各组件 (Tailwind dark: 前缀 / light? 三元表达式)
```

### 主题切换机制

`themeEngine.ts` 同时设置两个属性：

```typescript
export function applyTheme(mode: ThemeMode): void {
  document.documentElement.setAttribute('data-theme', mode);  // CSS 变量切换
  if (mode === 'dark') {
    document.documentElement.classList.add('dark');            // Tailwind dark: 前缀激活
  } else {
    document.documentElement.classList.remove('dark');
  }
}
```

- `data-theme="dark"` → 激活 `[data-theme="dark"]` 选择器的 CSS 变量
- `.dark` class → 激活 Tailwind `dark:` 前缀和 `.dark .xxx` 全局覆盖规则

### 三套主题配色

| 主题 | 背景色 | 文字色 | 强调色 |
|------|--------|--------|--------|
| 亮白 (`light`) | `#ffffff` | `#1f2937` | `#3b82f6` 蓝 |
| 暖色 (`warm`) | `#fefaf6` | `#4a3728` | `#c87941` 橙 |
| 暗色 (`dark`) | `#0f172a` | `#e2e8f0` | `#38bdf8` 天蓝 |

## 二、本次修复内容

### 修复 1：ProjectEntryPage.tsx — 硬编码 `light = true`

**文件**：`src/components/ProjectEntryPage.tsx`

**问题**：

```typescript
const light = true; // 固定浅色模式
```

该组件已定义完整的 `light ? 浅色 : 暗色` 三元样式体系（38 个样式变量），但 `light` 被硬编码为 `true`，暗色样式从未生效。

暗色模式下全局 CSS 将背景覆盖为深色（`#0f172a`），但标题文字仍为 `text-slate-800`（`#1e293b`），导致**深色文字 + 深色背景 = 对比度极差**。

**修复**：

```typescript
const light = typeof document !== 'undefined' && document.documentElement.dataset.theme !== 'dark';
```

与 `LoginPage.tsx` 的检测方式保持一致：
- 暗色模式 → `light = false` → 使用 `text-white`、`bg-white/5` 等暗色样式
- 亮白/暖色模式 → `light = true` → 使用原有浅色样式

### 修复 2：index.css — 补充 `text-gray-900` 全局暗色覆盖

**文件**：`src/index.css`

**问题**：`text-gray-900` 在暗色模式下无全局覆盖，`ContractReview.tsx` 中通过 `dangerouslySetInnerHTML` 生成的 HTML 使用了该类，暗色下不可见。

**修复**：

```css
/* index.css 第 189 行新增 */
.dark .text-gray-900 { color: #f1f5f9; }
```

与已有的 `text-gray-800` ~ `text-gray-400` 覆盖规则保持一致。

## 五、团队开发规范

### 新组件暗色适配 — 三选一

#### 方案 A：Tailwind `dark:` 前缀（推荐）

```tsx
<h1 className="text-slate-800 dark:text-slate-200">标题</h1>
<div className="bg-white dark:bg-slate-800 border-gray-200 dark:border-slate-700">卡片</div>
```

适用场景：新组件、简单组件。项目中最常用。

#### 方案 B：`light ?` 三元表达式

```tsx
const light = typeof document !== 'undefined' && document.documentElement.dataset.theme !== 'dark';

const styles = {
  title: light ? 'text-slate-800' : 'text-white',
  card: light ? 'bg-white shadow-md' : 'bg-white/5 backdrop-blur-xl',
};

<h1 className={`text-lg font-bold ${styles.title}`}>标题</h1>
```

适用场景：需要大量差异化样式（如渐变、毛玻璃效果）。参考 `ProjectEntryPage.tsx`、`LoginPage.tsx`。

#### 方案 C：CSS 变量

```tsx
<h1 className="text-[var(--text-primary)]">标题</h1>
<div className="bg-[var(--bg-card)]">卡片</div>
```

适用场景：P0/P1 新架构组件。参考 `TargetManager.tsx`、`AgentConsole.tsx`。

### 禁止事项

| 禁止 | 原因 | 替代方案 |
|------|------|---------|
| `const light = true` | 锁死浅色模式，暗色样式永不生效 | `document.documentElement.dataset.theme !== 'dark'` |
| 硬编码 `text-[#1e293b]` 等深色十六进制值 | 暗色下不可见，无法被覆盖 | `text-gray-800`（有全局覆盖）或 `dark:` 前缀 |
| 在 `dangerouslySetInnerHTML` 中使用无覆盖的颜色类 | 生成 HTML 不经 Tailwind 编译，`dark:` 前缀无效 | 使用已有全局覆盖的类（如 `text-gray-800`），或在 index.css 补充覆盖 |

### 新增颜色类的检查清单

引入新的文字/背景颜色类时，确认以下三项：

1. **是否有 `dark:` 前缀？** — 如 `text-slate-800 dark:text-slate-200`
2. **index.css 是否有全局覆盖？** — 如 `.dark .text-gray-800 { color: #e2e8f0; }`
3. **两者都没有？** — 必须补充其中一项，否则暗色下不可见
