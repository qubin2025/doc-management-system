# 配色方案规范

> 本文档定义全项目字体配色统一标准，所有组件必须遵循此规范。
> 最后更新：2026-08-12

## 一、色系选择

全项目统一采用 **slate（蓝调灰）** 色系，替代原 gray（中性灰）。

| 主题 | 背景色 | 适用场景 |
|------|--------|---------|
| 亮白模式 | `bg-white` / `bg-gray-50` | 白天默认 |
| 暖色模式 | `bg-[#fefaf6]` | 护眼 |
| 暗色模式 | `dark:bg-slate-900` / `dark:bg-slate-800` | 夜间 |

## 二、字体颜色层级

### 标准配色表

| 层级 | 亮色模式 | 暗色模式 | 用途 | 示例 |
|------|---------|---------|------|------|
| **主文本** | `text-slate-800` | `dark:text-slate-200` | 标题、数字、主内容 | h1、KPI 数值、表格数据 |
| **次要文本** | `text-slate-600` | `dark:text-slate-400` | 副标题、标签、数据说明 | 副标题、表单标签、列表项 |
| **辅助文本** | `text-slate-500` | `dark:text-slate-400` | 时间戳、底部信息、表头 | 时间、章节标签、表头 |
| **次级信息** | `text-slate-400` | `dark:text-slate-500` | 占位符、分隔符、图标 | "/"、 "-"、"至"、图标 |
| **占位/禁用** | `text-slate-300` | `dark:text-slate-600` | 空状态图标、禁用文字 | 占位图、空状态 |

### 特殊场景

| 场景 | 亮色模式 | 暗色模式 | 说明 |
|------|---------|---------|------|
| 背景图上的标题 | `text-slate-800` | `text-white` | 保证图片背景可读性 |
| 背景图上的副标题 | `text-slate-600` | `text-slate-300` | 略低于标题 |
| 强调链接 | `text-blue-600` | `dark:text-blue-400` | 可交互元素 |
| 危险/错误 | `text-red-600` | `dark:text-red-400` | 删除、警告 |

## 三、使用规范

### 3.1 强制规则

1. **成对出现**：每个 `text-slate-*` 必须配对 `dark:text-slate-*`，禁止单独使用
   ```tsx
   // ✅ 正确
   <h1 className="text-slate-800 dark:text-slate-200">标题</h1>

   // ❌ 错误（暗色模式缺失）
   <h1 className="text-slate-800">标题</h1>
   ```

2. **层级一致性**：同类元素在所有页面使用相同层级
   - 所有 h1 主标题 → `text-slate-800 dark:text-slate-200`
   - 所有副标题 → `text-slate-600 dark:text-slate-400`

3. **禁止 gray 色系**：新代码不允许出现 `text-gray-*`，统一用 `text-slate-*`

4. **视觉属性用 class**：颜色、字号必须用 Tailwind 类，禁止 inline style
   ```tsx
   // ✅ 正确
   <div className="h-[65px] text-slate-800 dark:text-slate-200">

   // ❌ 错误（inline style）
   <div style={{ height: '65px', color: '#1e293b' }}>
   ```

### 3.2 字号规范

| 档位 | Tailwind 类 | 像素值 | 用途 |
|------|------------|--------|------|
| 大 | `text-xl` | 20px | 页面主标题 |
| 中 | `text-lg` | 18px | 区块标题 |
| 标准 | `text-sm` | 14px | 正文、按钮 |
| 小 | `text-xs` | 12px | 标签、辅助文本 |

> 禁止使用 `text-[10px]`、`text-[11px]` 等硬编码小号字体，最小字号 ≥ 12px。

## 六、调试工具

项目内置颜色调试工具 [colorDebug.ts](../src/data/colorDebug.ts)，可在浏览器控制台查看当前生效的颜色配置。

- **开发模式**：自动输出颜色配置日志（`import.meta.env.DEV` 判断）
- **使用方式**：在组件 useEffect 中调用 `logColorConfig('ComponentName', themeMode)`
- **输出内容**：当前 className、light/dark 值、变更历史

## 八、维护指南

### 新增组件检查清单

- [ ] 字体颜色使用 `text-slate-*` 而非 `text-gray-*`
- [ ] 每个 `text-slate-*` 都配对 `dark:text-slate-*`
- [ ] 字号使用 `text-xs/sm/lg/xl`，无硬编码 `text-[Npx]`
- [ ] 视觉属性全部由 Tailwind class 驱动，无 inline style
- [ ] Logo 使用 `/zhjk-logo.png`

### 排查命令

```bash
# 查找缺失 dark 变体的 text-slate 类
grep -rn "text-slate-[0-9]00\"" src/components/ --include="*.tsx"

# 查找残留的 text-gray 类
grep -rn "text-gray-[0-9]00" src/components/ --include="*.tsx"

# 查找硬编码小号字体
grep -rn "text-\[1[0-1]px\]" src/components/ --include="*.tsx"
```
