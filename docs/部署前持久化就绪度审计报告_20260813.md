## 二、阻塞性问题（必须修复方可上线）

### 阻塞 1：6 类业务数据后端静默丢弃

**根因**：`syncService.ts` 每 60 秒收集 7 类 localStorage 数据 POST 到 `/api/sync`，但后端 [sync.js](file:///d:/AICODING0609/工程资料管理系统源码/backend/routes/sync.js) 只持久化 1 类（objectives），其余 6 类静默丢弃。

| syncService 收集 | 后端是否落库 | 影响 |
|------------------|-------------|------|
| objectives | ✅ 是 | 无 |
| **tailoring** | ❌ 丢弃 | 模块裁剪配置丢失 |
| **stakeholders** | ❌ 丢弃 | 干系人信息丢失 |
| **risks** | ❌ 丢弃 | 风险登记册丢失 |
| **resources** | ❌ 丢弃 | 资源配置丢失 |
| **raci** | ❌ 丢弃 | RACI 矩阵丢失 |
| **guideProgress** | ❌ 丢弃 | 指南完成进度丢失 |

**影响**：换浏览器 / 清缓存 / 多用户访问时，这 6 类数据全部丢失。表面上"已同步"，实际从未落库。

**修复方案**：扩展 `backend/routes/sync.js`，新增 `project_config` 通用表存储 JSON 配置，或为每类数据建专用表。

---

### 阻塞 2：指南进度键名不一致 Bug

**根因**：写入端和读取端使用了不同的 localStorage 键名。

| 端 | 键名 | 文件:行 |
|----|------|---------|
| **写入**（GuideChapter） | `guide-chapter-ch1-done`（无项目名） | [GuideChapter.tsx:202](file:///d:/AICODING0609/工程资料管理系统源码/src/components/GuideChapter.tsx) |
| **读取**（ProjectEntryPage） | `guide-${proj}-chapter-ch1-done`（带项目名） | [ProjectEntryPage.tsx:97](file:///d:/AICODING0609/工程资料管理系统源码/src/components/ProjectEntryPage.tsx) |
| **收集**（syncService） | done 带项目名 / modules 不带项目名（自相矛盾） | [syncService.ts:66](file:///d:/AICODING0609/工程资料管理系统源码/src/data/syncService.ts) |

**影响**：指南"完成项"数据被孤立——写入的键无人读取，读取的键无人写入。项目卡片上的指南进度永远显示 0%。

**修复方案**：统一为带项目名的键名 `guide-${proj}-chapter-ch${i}-done`，GuideChapter 写入时拼接项目名。

---

### 阻塞 3：saveGuideProgress / fetchGuideProgress 死代码

**根因**：[api.ts:658-675](file:///d:/AICODING0609/工程资料管理系统源码/src/data/api.ts) 已定义指南进度 API 函数，但全项目**零调用**。

**影响**：即使修复了键名 Bug，指南进度仍不会同步到后端。

**修复方案**：在 GuideChapter.tsx 的 useEffect 中接入 `saveGuideProgress`（写入时同步），初始化时接入 `fetchGuideProgress`（读取时加载）。

---

### 阻塞 4：项目重命名 / 详情更新无 API

**根因**：[App.tsx](file:///d:/AICODING0609/工程资料管理系统源码/src/App.tsx) 中两个处理器仅写 localStorage：

| 处理器 | 行号 | 当前行为 | 问题 |
|--------|------|---------|------|
| `onRenameProject` | L693 | 仅 `setProjects` + localStorage | 后端项目名永不更新 |
| `onUpdateProject` | L704 | 仅 `setProjects` + localStorage | 项目详情（概况/面积/投资/管线/AI报告）不落库 |

**影响**：用户编辑的项目信息在换浏览器后丢失。

**修复方案**：后端新增 `PUT /api/projects/:name` 端点，前端接入 `api.updateProject` / `api.renameProject`。
