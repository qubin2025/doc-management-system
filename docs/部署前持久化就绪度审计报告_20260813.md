## 六、延后项说明

### 6b：plan-files 持久化
- **现状**：`plan-files` 为全局 localStorage 键（PlanManager 组件无 projectName prop）
- **影响**：CPM/甘特计划数据在换浏览器后丢失
- **修复路径**：PlanManager 新增 projectName prop → 键改为 `plan-files-${projectName}` → 加入 syncService 收集
- **工作量**：中（涉及 PlanManager + App.tsx + GanttChart 联动）

### 7：数据模块直读 localStorage 缓存
- **现状**：indicatorEngine / financeMetrics / knowledgeGraph / projectAggregator 直接读 `doc-mgmt-projects-*` / `doc-mgmt-upload-*` localStorage 缓存
- **影响**：缓存为空时返回空数据（非错误，但不走 API 层）
- **修复路径**：4 个模块改为调用 api.fetchProjects / api.fetchDocuments
- **工作量**：大（架构重构，需逐模块改造）
